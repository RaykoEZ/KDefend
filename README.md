# Project - Kitchen Defender (WIP, title name STC)

A Top-down Arena-battler with exploration and mystery-solving elements.

The player begins the experience at the "end-times" of a corrupted game level from as a former-administrator entity. Much of the world have succumbed to the data corruption of an unknown source. 

The quest of addressing this problem will be the main focus of this game.

**Art Style:**
- 2D Pixel Art
- CEL-shaded (in illustrations)
- Cyberpunk

**Core Mechanics:**
1. **Top-down Combat**
    - Health Points as a currency
    - Projectile
    - Melee
    - Combat Items
2. **Exploration**
    - Regular Item spawns.
    - Item Interaction (Display 2D assets)
        - Trigger game events via special item interactions
    - NPC Dialogue affecting game states
    - "Insurmountable" enemies with removable mechanics through game events
    - Read/Write media files with clues to hidden secrets/puzzles
    - Potential multiple-endings/routes depending on player decisions
